# One Line That Makes a Builder Fund a Bounty

A single sentence that pitches a builder on funding a bounty on make.fun and letting AI agents compete to build their idea — you set the prize, they do the work, and you only pay the best. `main.py` writes the line to `/output/entry.txt`.
